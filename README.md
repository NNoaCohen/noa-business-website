# נועה הלוי — אתרים עם אופי

גרסה מעודכנת לפי העיצוב הראשון, בצבעי הלוגו ובפונט Heebo מקומי.

## הפעלה
```bash
npm install
npm run dev
```
פותחים http://localhost:3000. לבנייה: `npm run build`.

התוכן נמצא ב־`data/`, פרטי העסק והניווט ב־`config/`, העיצוב ב־`app/globals.css`, והרכיבים ב־`components/`. קובץ הלוגו המקורי ב־`public/logo-noa.png`. קובצי הפונט מצורפים ב־`public/fonts/`, כך שהאתר אינו צריך להוריד פונט בזמן השימוש.

יצירת קשר באמצעות מייל וחיוג. המחשות הפרויקטים הן המחשות עיצוביות, לא צילומי מסך.
